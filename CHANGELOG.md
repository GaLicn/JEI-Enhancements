# Changelog

## [1.1.0]

### Added / 新增
- 新增书签空白页操作，可添加空白页以独立保存书签
  - Added blank bookmark pages, allowing bookmarks to be stored independently by page.

### Changed / 变更
- 优化书签管理代码，增强新版 JEI 的兼容性与页面刷新稳定性
  - Optimized bookmark management code for improved compatibility with newer JEI versions and more reliable page refreshes.
- JEI 最低支持版本提高至 19.50.0.x
  - Raised the minimum supported JEI version to 19.50.0.x.
